职位名称：机器视觉开发工程师（工业视觉系统方向）
适用层级：本科，1—3 年或具备可验证项目/产线实践
岗位场景：3C、半导体、锂电、汽车零部件、精密装配及非标自动化检测设备

【岗位职责】
1. 对接客户、项目、机械和电气团队，澄清检测对象、缺陷类型、节拍、精度、视野、工作距离、安装空间及通信接口，完成视觉可行性评估、风险识别和技术方案设计。
2. 根据成像目标完成工业相机、镜头、光源、采集卡、触发方式和工控机等硬件评估与选型，搭建实验室原型并开展曝光、增益、焦距、景深、畸变和光照稳定性测试，输出选型依据、测试记录及 BOM。
3. 使用 HALCON、VisionPro、VisionMaster 或 OpenCV 开发视觉流程，覆盖图像预处理、标定、模板匹配、定位引导、尺寸测量、OCR/条码识别、外观缺陷检测及结果判定。
4. 使用 C#、C++ 或 Python 完成视觉应用软件或功能模块开发，设计配方、参数配置、图像显示、结果管理、日志、报警、权限及调试界面，保证代码结构清晰、便于维护。
5. 完成视觉系统与 PLC、运动控制器、机器人、相机、光源控制器及 MES/上位系统的通信和时序联调，处理 TCP/IP、串口、Modbus、数字 I/O、软/硬触发以及多设备协同问题。
6. 参与设备安装、标定、试运行、节拍优化和现场交付，定位成像波动、定位偏差、误检漏检、触发丢帧、通信中断和环境干扰等问题，推动机械、电气、软件和工艺问题闭环。
7. 建立样本与测试场景，结合真实工况验证重复性、稳定性、边界条件和异常恢复能力；对算法阈值、检测流程和成像方案持续优化，并保留可复核的测试结果。
8. 编写视觉方案、可行性报告、接口协议、软件说明、调试记录、操作手册和验收资料，沉淀配方、故障案例及标准化模块，支持后续复制和维护。

【任职要求】
1. 本科及以上学历，自动化、测控、光学、计算机、电子信息、机电一体化等相关专业；具备机器视觉、自动化设备或智能检测相关实践。
2. 理解机器视觉成像链路，掌握视野、分辨率、精度、焦距、工作距离、景深、曝光及光源方式之间的关系，能根据任务分析硬件和成像方案。
3. 熟悉 HALCON、VisionPro、VisionMaster、OpenCV 中至少一种，能够完成常见 2D 视觉任务的流程搭建、参数调试和问题排查。
4. 掌握 C#、C++、Python 中至少一种，具备面向对象、异常处理、日志、网络通信和基础多线程编程能力，能独立实现或维护视觉功能模块。
5. 熟悉工业相机与镜头光源的基本使用，理解 GigE Vision、USB3 Vision、软硬触发、图像缓存和常见丢帧原因；具备现场接线和软硬件联调意识。
6. 了解 PLC、伺服、运动控制、机器人或工业通信，能够读懂设备流程和接口文档，并与机械、电气、工艺团队协作完成系统集成。
7. 具备需求分析、实验验证、故障定位和技术文档能力；能够适应车间环境、中短期出差和项目交付节奏。

【加分项】
1. 有 AOI、半导体、3C、锂电或精密尺寸测量项目经验，能够说明本人负责的模块、使用工具、交付物和验证方式。
2. 有多相机、多工位、机器人引导、运动控制或视觉与 AI 检测协同经验。
3. 了解深度学习缺陷检测、ONNX/TensorRT 等部署流程，或有视觉软件平台化、配方化、追溯与断线恢复设计经验。
4. 有设备现场验收、客户培训、技术文档标准化或复杂故障闭环经验。

【岗位核心关键词】
机器视觉；工业相机；镜头；光源；成像；标定；定位；尺寸测量；OCR；缺陷检测；HALCON；VisionPro；VisionMaster；OpenCV；C#；C++；Python；PLC；运动控制；工业通信；系统集成；现场调试；项目交付
