职位名称：工业上位机软件工程师（C#/.NET 设备控制方向）
适用层级：本科，1—3 年或具备可运行工业软件项目
岗位场景：自动化设备、视觉检测设备、运动控制平台、智能仪器及生产线信息化

【岗位职责】
1. 参与自动化设备上位机的需求分析、总体方案和模块设计，使用 C#/.NET 开发设备控制、状态监控、参数配方、报警、数据采集、生产记录及操作界面。
2. 基于 WinForms 或 WPF 实现稳定、清晰的工业桌面应用，完成自定义控件、数据绑定、实时曲线、图像显示、权限管理、配置管理和多语言等功能。
3. 设计设备流程与状态机，封装 PLC、运动控制卡、机器人、工业相机、扫码器、传感器及其他下位设备的控制和数据接口，保障指令、状态与异常处理逻辑一致。
4. 开发并维护 TCP/UDP、Socket、RS232/485、Modbus TCP/RTU、OPC UA、EtherCAT 或厂商 SDK 等通信模块，实现心跳、超时、重试、断线重连、报文校验和通信日志。
5. 使用多线程、异步、事件驱动和生产者—消费者等机制处理设备实时数据与 UI 更新，解决界面卡顿、线程冲突、资源泄漏、阻塞和异常退出问题。
6. 设计 SQLite、SQL Server 或 MySQL 数据结构，实现配方、检测结果、报警、用户操作和追溯数据的可靠存储、查询、导出与备份；按项目需要对接 MES、ERP 或文件接口。
7. 与机械、电气、视觉和工艺工程师联合调试设备，完成 I/O、运动、相机触发、视觉结果、工艺流程及安全互锁联调，快速复现并定位软硬件协同问题。
8. 负责软件部署、版本管理、升级维护、现场支持和性能优化，编写需求说明、设计文档、接口协议、测试用例、发布说明、用户手册及故障排查文档。

【任职要求】
1. 本科及以上学历，计算机、软件工程、自动化、电气、测控、机电一体化等相关专业；有工业设备软件、控制软件或仪器软件实践。
2. 熟练使用 C#，理解面向对象、接口、委托、事件、泛型、异常处理及常用设计模式；熟悉 .NET Framework 或现代 .NET 的桌面开发。
3. 熟悉 WinForms 或 WPF；理解 UI 线程、数据绑定、多线程、Task/async/await、线程同步和资源生命周期，能够编写长期运行的设备软件。
4. 熟悉至少两类工业通信或设备接口，能够根据协议文档实现数据解析、异常检测、日志记录和重连机制。
5. 具备数据库基础，能完成表结构设计、增删改查、事务和常用查询优化；理解配置、日志、报警和生产追溯的工程需求。
6. 理解 PLC、伺服、步进、气缸、传感器、视觉相机及运动控制基本原理，能读懂设备流程、电气信号或 SDK 示例并完成联调。
7. 具备代码调试、问题复现、版本控制、模块化设计和技术文档能力，重视异常恢复、可维护性和现场可诊断性。
8. 具备良好沟通协作和交付意识，可适应设备现场调试及必要出差。

【加分项】
1. 有固高、雷赛、研华、正运动或 EtherCAT 总线运动控制开发经验，理解回零、限位、点位运动、插补、同步和 I/O 联动。
2. 有机器视觉软件、多相机图像处理、共享内存/进程通信、配方管理、生产追溯或断线恢复经验。
3. 熟悉 WPF/MVVM、依赖注入、状态机、单元测试、CI/CD、性能分析或软件平台化设计。
4. 有 MES/ERP/AGV/WMS 接口、设备数据报工、远程诊断、软件部署培训或量产维护经验。

【岗位核心关键词】
C#；.NET；WinForms；WPF；MVVM；工业上位机；状态机；多线程；异步；TCP/IP；Socket；Modbus；RS232/485；OPC UA；EtherCAT；运动控制卡；PLC；工业相机；数据库；MES；日志；报警；配方；追溯；设备联调
