职位名称：工业视觉算法工程师（传统视觉与深度学习方向）
适用层级：本科/硕士，1—3 年或具有高质量算法项目、论文/竞赛及工程验证成果
岗位场景：半导体、显示面板、PCBA、3C、锂电、汽车零部件及智能质检

【岗位职责】
1. 面向工业缺陷检测、目标定位、尺寸测量、OCR/条码和分类识别任务，分析业务需求、样本特性、误检漏检成本与部署约束，制定传统视觉、深度学习或混合算法方案。
2. 负责数据采集、筛选、清洗、标注规范、训练/验证/测试集划分和难例管理，识别类别不均衡、脏数据、域偏移及数据泄漏等风险，建立可持续迭代的数据闭环。
3. 使用 OpenCV、HALCON 等实现滤波、增强、阈值分割、形态学、边缘/轮廓、模板匹配、几何测量、配准及特征提取等传统图像算法。
4. 使用 PyTorch 或 TensorFlow 开展分类、目标检测、语义/实例分割、OCR、异常检测等模型训练与优化，完成损失函数、数据增强、超参数、消融和对比实验。
5. 建立与业务目标一致的评估体系，使用 Precision、Recall、F1、mAP、IoU、混淆矩阵、ROC/PR、推理时间及资源占用等指标分析模型，并按缺陷类型、产品批次和成像条件进行分层验证。
6. 完成算法模块的代码实现、接口封装、单元/回归测试和性能优化；按项目需要使用 ONNX、ONNX Runtime、TensorRT、OpenVINO 等进行模型转换、加速与部署。
7. 与视觉软件、光学、电气、工艺和现场团队协作，将算法接入图像采集、配方、设备节拍和判定流程；定位图像质量、数据分布、算法逻辑、硬件资源及工艺变化引起的问题。
8. 跟踪工业视觉、异常检测、小样本、无监督/半监督、模型轻量化和视觉大模型等技术，进行可复现实验并判断其实际适用边界，沉淀算法文档、测试报告和版本记录。

【任职要求】
1. 本科及以上学历，计算机、人工智能、自动化、电子信息、数学、测控等相关专业；具备图像处理、机器学习或工业视觉相关项目实践。
2. 掌握 Python，具备 C++ 基础或工程开发能力；理解数据结构、算法复杂度、面向对象、调试、版本控制和基本软件工程规范。
3. 掌握数字图像处理和计算机视觉基础，理解卷积、频域、颜色空间、几何变换、特征、分割、检测和评价指标等核心概念。
4. 熟悉 OpenCV，并掌握 PyTorch/TensorFlow 中至少一种；能够独立完成数据处理、模型训练、结果分析和可复现验证。
5. 熟悉至少一类目标检测、分类或分割模型，理解过拟合、正则化、数据增强、学习率、类别不均衡和阈值选择对结果的影响。
6. 能基于业务约束分析误检、漏检、泛化、节拍和资源占用之间的取舍，不仅汇报单一准确率；具备问题拆解和实验设计能力。
7. 了解工业相机、镜头、光源和触发等成像基础，能够判断图像问题与算法问题的边界，并与工程团队协同完成落地。
8. 具备清晰的代码、实验记录和技术文档习惯，能够阅读英文资料并持续学习。

【加分项】
1. 有半导体、面板、PCBA、3C、锂电等工业缺陷检测或 OCR 项目，能够说明数据规模边界、指标定义、本人贡献和部署结果。
2. 有小样本、少样本、异常检测、无监督/半监督、噪声鲁棒性或多传感器融合研究与验证经历。
3. 有 ONNX/TensorRT/OpenVINO 部署、CUDA/GPU 推理优化、C++ 算法库封装或 Windows 工业软件集成经验。
4. 具备完整的算法生命周期经验：数据规范、训练、评估、部署、现场回流、版本迭代和性能监控。

【岗位核心关键词】
工业视觉；缺陷检测；图像处理；OpenCV；HALCON；Python；C++；PyTorch；TensorFlow；目标检测；YOLO；图像分类；语义分割；实例分割；OCR；异常检测；数据标注；Precision；Recall；F1；mAP；ONNX；TensorRT；模型部署；性能优化
