# 工程技术岗位母版 JD

更新日期：2026-08-29

## 用途

本目录的五份 JD 是用于造途 ZAOTU 匿名封测和岗位证据匹配的公开测试资料，不是任何一家企业正在招聘的原文，也不应冒充具体公司的招聘信息。

每份母版综合多家真实岗位的高频职责、硬技能和加分项，并按工程技术岗位方向划清边界：

- 机器视觉开发工程师：视觉方案、成像、传统视觉、软件与设备落地。
- 工业上位机工程师：C#/.NET、工业通信、运动控制、数据与软件稳定性。
- 工业视觉算法工程师：传统图像算法、深度学习、数据闭环、评估与部署。
- 自动化设备测试工程师：需求到用例、整机功能/性能/稳定性、问题定位与回归。
- 电气自动化工程师：电控方案、图纸/BOM、PLC/HMI、伺服与整机联调。

## 使用方法

1. 在造途中选择一份母版作为测试 JD，用于检查不同岗位方向的证据选择、缺口提示和材料差异。
2. 真正投递时，仍应把目标公司的原始 JD 输入系统，再由系统从对应方向基础上重排证据；不要直接把母版当成某家公司的岗位。
3. 母版中出现的技能只是招聘方需求，不代表候选人已经掌握。简历仍只能调用职业背景库中的确认事实；没有的能力进入缺口和面试准备，不能写成既有经历。
4. “算法工程师”按工业视觉算法定义；“测试工程师”按自动化设备、智能硬件与整机系统测试定义。若未来投互联网软件测试或通用大模型算法，应另建母版。
